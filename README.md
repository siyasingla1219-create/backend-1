# Smart Utility Toolkit 🚀

## 📖 Project Description

Smart Utility Toolkit is a simple Node.js project that demonstrates the use of important built-in Node.js modules. The project includes a command-line calculator, custom modules, a basic HTTP server, a file manager, and a secure random dice generator.

This project helps demonstrate practical usage of:

- `process.argv`
- Custom Modules
- `http` module
- `fs` (File System) module
- `crypto` module
